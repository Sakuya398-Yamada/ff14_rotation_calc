# FF14 ローテーション計算ツール

[English](./README.en.md)

FF14（ファイナルファンタジー14）のスキル回し（ローテーション）の **期待威力・PPS（Potency Per Second）を自動計算する Web ツール** です。

タイムライン上にスキルを並べるだけで、バフ・DoT・リキャストを加味した期待値がリアルタイムに算出されます。

---

## できること

- スキルをタイムラインに並べて **期待威力・PPS を自動計算**
- バフ・デバフの相乗を加味したダメージ期待値の算出
- DoT（継続ダメージ）・リキャストの可視化
- ステータス値（クリティカル・ダイレクトヒット・意思力・スピード）に応じた補正
- ボス離脱タイミングや PPS 集計範囲の指定

## 基本操作の流れ

1. **ジョブとレベルを選択する**
   - 画面上部のジョブピッカー（選択中のジョブ名のボタン）を押し、開いたパネルで対応ジョブとレベルを選ぶ（モードはリボーンモードのまま）
2. **スキルをタイムラインに配置する**
   - ジョブパレットに並んだスキルアイコンを、右側のタイムラインへドラッグ＆ドロップ
3. **タイムライン上で並び替える**
   - 配置済みのスキルをドラッグで左右に動かし、順序を調整
4. **期待威力・PPS を確認する**
   - 並べるたびに自動計算され、画面上部の集計バーに反映されます

## 画面の説明

### ヘッダー（画面上部）

- **ジョブピッカー**: 選択中のジョブとレベルを表示するボタン。押すとパネルが開き、ジョブとレベルを選べます
  - ジョブは名前・略称で絞り込めます（例: 「黒」「BLM」）。最近使ったジョブも並びます。未対応のジョブは選べません
  - **モード**: リボーンモード（今までと同じ操作）で計算します。エヴォルヴモード（パッチ 8.0 から）は未対応で、選べません
  - **レベル（α版）**: 70 / 80 / 90 / 100 から選べます。Lv100 以外のスキルの有無・威力は参考値のためアルファ版扱いです。Lv110（パッチ 8.0 から）は未対応で、選べません
- **設定**（歯車のボタン）: 表示する言語（日本語 / English）、画面のテーマ（ライト / ダーク / OS に合わせる）、アクセントカラーを変えられます
  - 言語の「English」を押すと、同じページの英語版を開きます。作業中のタイムラインはそのまま引き継がれます（英語版では「日本語」を押すと日本語版に戻れます）
  - 「アカウント」の「Discord でログイン」で、Discord のアカウントでログインできます。ログイン中は、同じ場所に「ログアウト」のボタンが出ます。ログインすると、保存したタイムラインの一覧を別のブラウザや別の端末でも見られます（FAQ の「[保存したタイムラインをあとから探したい](#q-保存したタイムラインをあとから探したい)」）。ログインで扱う情報は、同じ欄の「プライバシーポリシー」に書いてあります
- **保存・共有**: 保存したタイムラインの一覧を開きます。今のタイムラインの保存も、この一覧の「今のタイムラインを保存」から行います。使い方は、FAQ の「[タイムラインを共有したい・別の端末で開きたい](#q-タイムラインを共有したい別の端末で開きたい)」「[保存したタイムラインをあとから探したい](#q-保存したタイムラインをあとから探したい)」を参照してください
- **Mint Leaf に書き出す**: 今のタイムラインを、[Mint Leaf](https://mint-leaf.thebalanceffxiv.com/)（The Balance のスキル回し作成サイト）の「Import / Export」欄に貼れるテキストにして、コピーできます
  - ジョブ・レベル・タイトルはテキストに入らないので、Mint Leaf の画面上部で選んでください
  - 書き出すのは、スキルの並びと、GCD のリキャスト・詠唱時間（スキルスピードやバフを反映したこのツールの計算値）だけです。開始時刻の指定・oGCD を挟むタイミング・バフは書き出しません

### 集計バー（ヘッダーの下）

| 項目 | 内容 |
|------|------|
| 合計期待威力 | 0 秒から最後の GCD のリキャストが終わる時刻（詠唱がリキャストより長いスキルなら詠唱が終わる時刻）までに着弾した期待威力（DoT を含む。それより後の DoT のティックは数えない）。GCD が無いときは、置いたスキルと DoT のすべての期待威力 |
| PPS 全体 | 合計期待威力 ÷ 所要時間（「PPS 範囲選択」の「全体」と同じ範囲の PPS） |
| PPS 区間 | 「PPS 範囲選択」で指定した範囲の PPS |
| DoT 期待威力 | 合計期待威力のうち、DoT の分 |
| 所要時間 | 最後の GCD のリキャストが終わる時刻（詠唱がリキャストより長いスキルなら詠唱が終わる時刻）。DoT がそれより後まで続くときは、最後の DoT のティックの時刻を添える（GCD が無いときは、最後の DoT のティックか最後にスキルが着弾した時刻の遅い方） |

### ジョブパレット（画面左）

- **ステータス入力欄**: クリティカル・ダイレクトヒット・意思力・スピード（スキル/スペルスピード）。入力値から求めた発生率・倍率・GCD も表示されます
- そのジョブで使えるスキル一覧（GCD / oGCD に分けて表示。各スキルに威力を併記）

### タイムライン（画面右）

複数のレーンに分かれています。

| レーン | 内容 |
|--------|------|
| GCD | 通常攻撃・リキャスト中の主要スキル |
| oGCD | アビリティ（ウィービング枠） |
| リソース | ジョブゲージ・スタック系リソース |
| バフ | 自己バフ・パーティバフの効果時間 |
| リキャスト | 個別スキルのリキャスト状態 |
| DoT | 継続ダメージの効果時間 |

レーン（左のラベルを除く）をマウスでダブルクリックすると（タッチ端末のダブルタップには対応していません）、その位置に縦線が引かれ、その時刻のリソース（値 / 上限）とリキャスト（使用可能か、残り秒数。チャージ式はチャージ数と次のチャージまでの秒数）がタイムラインの下のパネルに出ます。残り秒数の横の「＞」を開くと、その後に使うスキルによる短縮も込みで、実際にリキャストが戻る時刻が見られます。パネルを開いたままタイムラインを編集すると、同じ時刻のまま値が更新されます。パネルは閉じるボタンで閉じます（スキルをクリックすると、スキル詳細パネルに入れ替わります）。

### 計算範囲の指定

- **PPS 範囲選択**: 威力総計・PPS を計算する時間範囲を指定できます
- **ボス離脱タイミング**: ボスが離脱（ターゲット不能）になる時刻を指定できます。離脱中は威力が発生しないため、計算から除外されます
- **複数体ウィンドウ**: 敵の数と、その数の敵がいる時間帯を指定できます。この時間帯に使った範囲スキルは、指定した数の敵に当たったものとして威力を計算します（対象数の上限と威力の減衰はスキルごとに反映。DoT は 1 体分で計算します）
- **着弾までの遅れ**: スキルの詳細パネルで、そのスキルを実行してから着弾するまでの秒数を設定できます（同じスキルすべてに効きます。詠唱のあるスキルは詠唱完了から数えます）。スキルは着弾した時刻で PPS 範囲・集計に入り、そのスキルが付けるバフ・シナジーも着弾した時刻から効きます（効果時間も着弾から数えます。着弾より前に使ったスキルには乗りません）。DoT も着弾した時刻に付き、効果時間とティックを着弾から数えます（同時に 1 種類だけの DoT の付け替えと、DoT の延長も着弾した時刻に行います）。設定していなければ遅れは 0 秒で、詠唱のあるスキルは詠唱完了の時刻、無いスキルは使った時刻に着弾します。威力に掛かるバフの判定は、実機と同じく実行した時刻のままです（DoT のティックも、実行した時刻のバフで計算します）。リソースの増減も実行した時刻に行います。実行した時刻はボス離脱の外でも、着弾した時刻にボスが離脱中なら、威力は 0 になり、そのスキルが付けるバフ・シナジーと DoT も付きません（リソースの増減・コンボ・リキャストはそのまま起きます。スキルには警告が出ます）。暗黒騎士の影身具現の分身のように、使ってから決まった遅れで何回かに分けて入る攻撃は、各攻撃が着弾した時刻で PPS 範囲・集計に入り、威力に掛かるバフと敵の数も各攻撃が着弾した時刻で判定します（着弾と同じ時刻に付くバフは乗りません。設定した着弾までの遅れは足しません）

## 制限事項

本ツールは「単体ボスに対する火力ローテーション」の計算に特化しています（タンク・ヒーラーも、攻撃スキルの威力だけを計算します）。以下は **未対応** です。

- **味方対象のスキルは対象外**
  - 回復・軽減・味方バフ・シールド等は計算に含まれません（ヒーラー・タンクの支援系スキルは未対応）
- **方向指定は成功前提、距離減衰は未考慮**
  - 側面／背面の方向指定ボーナスは、方向指定に成功した前提で威力に含めています（モンク・侍・竜騎士）
  - 方向指定の成功／失敗は切り替えられません（トゥルーノースは効果を持たず、リキャスト管理用に配置できるだけです）
  - 範囲スキルの距離減衰は反映されません
- **単体ボス想定**
  - 複数ヒット・複数対象の威力計算は、一部スキルのみ対応しています
- **レベルは Lv100 を前提**
  - レベル設定は α 版機能です。Lv100 未満では威力値が正確でない可能性があります
- **動作保証はしていません**
  - 公式の計算式・スキル仕様とズレがある可能性があります。最終的な判断はゲーム内実測と併用してください

## FAQ

### Q. 威力計算が公式や他ツールと微妙に違う

本ツールの計算式は独自実装です。バフの重複順序・小数処理・ヒット期待値モデルの違いで、数%単位のズレが出る場合があります。目的は **ローテーション同士の相対比較** であり、絶対値の厳密な一致は保証していません。

### Q. スキルのアイコンが欠けている / 表示されない

アイコン画像はジョブ・スキル追加時に個別に登録しています。未登録のものや URL 切れで欠ける場合があります。Issue 起票いただければ差し替えます。

### Q. 使いたいジョブが未対応

現状 WHM / DRG / BRD / PCT / BLM / SAM / MNK / SCH / AST / SGE / PLD / WAR / GNB / DRK / MCH / DNC の 16 ジョブのみ対応しています。他ジョブは順次追加予定です。要望は Issue へどうぞ。

### Q. データは保存される？

編集中の内容（選択中のジョブ・レベル・ステータス・タイムライン・ボス離脱タイミングなど）は、ブラウザの LocalStorage に自動で保存されます。同じブラウザであれば、リロードしたりタブを閉じて開き直したりしても、前回の状態から再開できます。

- 自動保存の保存先は、お使いのブラウザの中だけです。ブラウザの閲覧データ（サイトデータ）を消すと、自動保存した内容も消えます（次の「保存・共有」でサーバーに保存したタイムラインは消えません。ただし、ログインせずに保存し、アカウントに紐づけていないものは、保存したタイムラインの一覧には出なくなります。共有 URL からは開けます。アカウントに紐づけたものは、もう一度ログインすれば一覧に出ます）
- 自動保存した内容は、別のブラウザや別の端末には引き継がれません。別の端末で開きたいときや、人に見せたいときは、次の「保存・共有」を使ってください

### Q. タイムラインを共有したい・別の端末で開きたい

画面上部の「保存・共有」で開く一覧の「今のタイムラインを保存」から、タイムラインをサーバーに保存すると、共有 URL が発行されます。この URL を開くと、別のブラウザや別の端末でも同じタイムラインを開けます。タイトルは任意で、100 文字まで付けられます。コンテンツ（黄金のレガシーの零式と、各拡張の絶）も任意で選べます。

- URL を知っている人は、誰でもそのタイムラインを開けます
- 保存したタイムライン・タイトル・コンテンツは、あとから変更できません。編集して保存し直すと、別の URL になります。削除は、次の保存したタイムラインの一覧からできます
- 共有 URL を開くと、作業中のタイムラインは共有されたものに置き換わります（作業中にエントリがあるときは、置き換える前に確認が出ます）
- 共有 URL を開くと、保存するときに選んだコンテンツと付けたタイトルが、画面上部に表示されます
- 共有 URL から開いたタイムラインを編集して保存しても、元のタイムラインは変わりません（複製として、別の URL で保存されます）
- 保存した人が削除したタイムラインは、共有 URL から開けません（開くと、削除されたことが表示されます）
- 短時間に続けて保存・削除すると、しばらく保存も削除もできなくなります
- 保存画面を開くと、ボット対策の確認（Cloudflare の [Turnstile](https://www.cloudflare.com/ja-jp/application-services/products/turnstile/)）が表示され、確認が終わるまで保存できません。確認のために、ブラウザの情報が Cloudflare に送られます（保存画面を開いたときだけ）

### Q. 保存したタイムラインをあとから探したい

画面上部の「保存・共有」から、保存したタイムラインを新しい順に一覧できます。共有 URL を控え忘れても、一覧から選んで開けます。一覧の各行は共有 URL へのリンクなので、新しいタブでも開けます。

- ログインしていなければ、一覧に出るのは同じブラウザで保存したものだけです（ブラウザの Cookie で見分けています）。別のブラウザや別の端末で保存したものは出ません
- 画面上部の設定（歯車のボタン）の「アカウント」から Discord でログインすると、そのアカウントで保存したものが一覧に出ます。別のブラウザや別の端末でも、同じアカウントでログインすれば同じ一覧を見られます。一覧の「Discord でログイン」からもログインできます
  - ログインすると、そのブラウザでログインせずに保存したものも、アカウントに紐づきます
  - ログアウトすると、そのブラウザの一覧は空になります。ログアウトしないまま、ログインのセッションが切れたときも同じです。保存したものはアカウントに残り、もう一度ログインすれば一覧に出ます
- 一覧の各行の「コピー」で、その行の共有 URL をコピーできます
- 一覧の各行のゴミ箱のボタンで、保存したタイムラインを削除できます。削除すると、共有 URL からも開けなくなります（URL を渡した相手も開けなくなります）。元に戻せません
- ブラウザの閲覧データ（サイトデータ）を消したときや、保存も一覧の表示もしないまま 400 日たったときは、それまでにログインせずに保存し、アカウントに紐づけていないものが一覧に出なくなり、削除もできなくなります。タイムライン自体はサーバーに残るので、共有 URL からは開けます。アカウントに紐づけたものは、ログインすれば一覧に出ます
