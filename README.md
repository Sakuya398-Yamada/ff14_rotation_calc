# FF14 ローテーション計算ツール

FF14（ファイナルファンタジー14）のスキル回し（ローテーション）の **期待威力・PPS（Potency Per Second）を自動計算する Web ツール** です。

タイムライン上にスキルを並べるだけで、バフ・DoT・リキャストを加味した期待値がリアルタイムに算出されます。

---

## できること

- スキルをタイムラインに並べて **期待威力・PPS を自動計算**
- バフ・デバフの相乗を加味したダメージ期待値の算出
- DoT（継続ダメージ）・リキャストの可視化
- ステータス値（クリティカル・ダイレクトヒット・意思力・スピード）に応じた補正
- ボス離脱タイミングや PPS 集計範囲の指定

## 基本操作の流れ

1. **ジョブとレベルを選択する**
   - 画面上部のジョブピッカー（選択中のジョブ名のボタン）を押し、開いたパネルで対応ジョブとレベルを選ぶ
2. **スキルをタイムラインに配置する**
   - ジョブパレットに並んだスキルアイコンを、右側のタイムラインへドラッグ＆ドロップ
3. **タイムライン上で並び替える**
   - 配置済みのスキルをドラッグで左右に動かし、順序を調整
4. **期待威力・PPS を確認する**
   - 並べるたびに自動計算され、画面上部の集計バーに反映されます

## 画面の説明

### ヘッダー（画面上部）

- **ジョブピッカー**: 選択中のジョブとレベルを表示するボタン。押すとパネルが開き、ジョブとレベルを選べます
  - ジョブは名前・略称で絞り込めます（例: 「黒」「BLM」）。最近使ったジョブも並びます。未対応のジョブは選べません
  - **レベル（α版）**: 70 / 80 / 90 / 100 から選べます。Lv100 以外のスキルの有無・威力は参考値のためアルファ版扱いです
- **設定**（歯車のボタン）: 画面のテーマ（ライト / ダーク / OS に合わせる）とアクセントカラーを変えられます
- 「保存・共有」「保存したタイムライン」の使い方は、FAQ の「[タイムラインを共有したい・別の端末で開きたい](#q-タイムラインを共有したい別の端末で開きたい)」「[保存したタイムラインをあとから探したい](#q-保存したタイムラインをあとから探したい)」を参照してください

### 集計バー（ヘッダーの下）

| 項目 | 内容 |
|------|------|
| 合計期待威力 | タイムライン全体の期待威力（DoT を含む） |
| PPS 全体 | タイムライン全体の PPS |
| PPS 区間 | 「PPS 範囲選択」で指定した範囲の PPS |
| DoT 期待威力 | DoT の期待威力の合計 |
| 所要時間 | 最後の GCD のリキャストが終わる時刻と、DoT の最終ティックの遅い方までの時間 |

### ジョブパレット（画面左）

- **ステータス入力欄**: クリティカル・ダイレクトヒット・意思力・スピード（スキル/スペルスピード）。入力値から求めた発生率・倍率・GCD も表示されます
- そのジョブで使えるスキル一覧（GCD / oGCD に分けて表示。各スキルに威力を併記）

### タイムライン（画面右）

複数のレーンに分かれています。

| レーン | 内容 |
|--------|------|
| GCD | 通常攻撃・リキャスト中の主要スキル |
| oGCD | アビリティ（ウィービング枠） |
| リソース | ジョブゲージ・スタック系リソース |
| バフ | 自己バフ・パーティバフの効果時間 |
| リキャスト | 個別スキルのリキャスト状態 |
| DoT | 継続ダメージの効果時間 |

### 計算範囲の指定

- **PPS 範囲選択**: 威力総計・PPS を計算する時間範囲を指定できます
- **ボス離脱タイミング**: ボスが離脱（ターゲット不能）になる時刻を指定できます。離脱中は威力が発生しないため、計算から除外されます
- **複数体ウィンドウ**: 敵の数と、その数の敵がいる時間帯を指定できます。この時間帯に使った範囲スキルは、指定した数の敵に当たったものとして威力を計算します（対象数の上限と威力の減衰はスキルごとに反映。DoT は 1 体分で計算します）

## 制限事項

本ツールは「DPS ロールの単体ボスに対する火力ローテーション」の計算に特化しています。以下は **未対応** です。

- **味方対象のスキルは対象外**
  - 回復・軽減・味方バフ・シールド等は計算に含まれません（ヒーラー・タンクの支援系スキルは未対応）
- **方向指定は成功前提、距離減衰は未考慮**
  - 側面／背面の方向指定ボーナスは、方向指定に成功した前提で威力に含めています（モンク・侍・竜騎士）
  - 方向指定の成功／失敗は切り替えられません（トゥルーノースは効果を持たず、リキャスト管理用に配置できるだけです）
  - 範囲スキルの距離減衰は反映されません
- **単体ボス想定**
  - 複数ヒット・複数対象の威力計算は、一部スキルのみ対応しています
- **レベルは Lv100 を前提**
  - レベル設定は α 版機能です。Lv100 未満では威力値が正確でない可能性があります
- **動作保証はしていません**
  - 公式の計算式・スキル仕様とズレがある可能性があります。最終的な判断はゲーム内実測と併用してください

## FAQ

### Q. 威力計算が公式や他ツールと微妙に違う

本ツールの計算式は独自実装です。バフの重複順序・小数処理・ヒット期待値モデルの違いで、数%単位のズレが出る場合があります。目的は **ローテーション同士の相対比較** であり、絶対値の厳密な一致は保証していません。

### Q. スキルのアイコンが欠けている / 表示されない

アイコン画像はジョブ・スキル追加時に個別に登録しています。未登録のものや URL 切れで欠ける場合があります。Issue 起票いただければ差し替えます。

### Q. 使いたいジョブが未対応

現状 WHM / DRG / BRD / PCT / BLM / SAM / MNK / SCH / AST / SGE の 10 ジョブのみ対応しています。他ジョブは順次追加予定です。要望は Issue へどうぞ。

### Q. データは保存される？

編集中の内容（選択中のジョブ・レベル・ステータス・タイムライン・ボス離脱タイミングなど）は、ブラウザの LocalStorage に自動で保存されます。同じブラウザであれば、リロードしたりタブを閉じて開き直したりしても、前回の状態から再開できます。

- 自動保存の保存先は、お使いのブラウザの中だけです。ブラウザの閲覧データ（サイトデータ）を消すと、自動保存した内容も消えます（次の「保存・共有」でサーバーに保存したタイムラインは消えません。ただし「保存したタイムライン」の一覧には出なくなります。共有 URL からは開けます）
- 自動保存した内容は、別のブラウザや別の端末には引き継がれません。別の端末で開きたいときや、人に見せたいときは、次の「保存・共有」を使ってください

### Q. タイムラインを共有したい・別の端末で開きたい

画面上部の「保存・共有」からタイムラインをサーバーに保存すると、共有 URL が発行されます。この URL を開くと、別のブラウザや別の端末でも同じタイムラインを開けます。タイトルは任意で、100 文字まで付けられます。コンテンツ（黄金のレガシーの零式と、各拡張の絶）も任意で選べます。

- URL を知っている人は、誰でもそのタイムラインを開けます
- 保存したタイムライン・タイトル・コンテンツは、あとから変更・削除できません。編集して保存し直すと、別の URL になります
- 共有 URL を開くと、作業中のタイムラインは共有されたものに置き換わります（作業中にエントリがあるときは、置き換える前に確認が出ます）
- 共有 URL を開くと、保存するときに選んだコンテンツと付けたタイトルが、画面上部に表示されます
- 共有 URL から開いたタイムラインを編集して保存しても、元のタイムラインは変わりません（複製として、別の URL で保存されます）
- 短時間に続けて保存すると、しばらく保存できなくなります
- 保存画面を開くと、ボット対策の確認（Cloudflare の [Turnstile](https://www.cloudflare.com/ja-jp/application-services/products/turnstile/)）が表示され、確認が終わるまで保存できません。確認のために、ブラウザの情報が Cloudflare に送られます（保存画面を開いたときだけ）

### Q. 保存したタイムラインをあとから探したい

画面上部の「保存したタイムライン」から、このブラウザで保存したタイムラインを新しい順に一覧できます。共有 URL を控え忘れても、一覧から選んで開けます。一覧の各行は共有 URL へのリンクなので、新しいタブで開いたり、URL をコピーしたりもできます。

- 一覧に出るのは、同じブラウザで保存したものだけです（ログインは無く、ブラウザの Cookie で見分けています）。別のブラウザや別の端末で保存したものは出ません
- ブラウザの閲覧データ（サイトデータ）を消したときや、保存も一覧の表示もしないまま 400 日たったときは、それまでに保存したものが一覧に出なくなります。タイムライン自体はサーバーに残るので、共有 URL からは開けます
